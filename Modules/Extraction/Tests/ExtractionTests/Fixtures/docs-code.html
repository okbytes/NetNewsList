Configuring the Build Cache

The build cache stores the outputs of previous builds so that unchanged steps can be skipped. This guide explains how to enable it, how to size it, and how to share it between machines on the same network.

Setup

Add the following section to your configuration file. The maxSize value is in megabytes, and the cache evicts the least recently used entries when it is full.

[cache]
enabled = true
maxSize = 2048
path = "~/.cache/example"

After changing the file, restart the build daemon so that it picks up the new settings. You can confirm the cache is active by running the status command and looking for the cache line in its output.

$ example status
cache: enabled (2048 MB, 12% used)

Frequently asked questions

Sharing a cache across machines requires that every machine use the same toolchain version, otherwise the cache keys will not match and every build will miss.
